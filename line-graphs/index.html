Line Graphs

DS 2023 | Communicating with Data

Overview¶

Bar charts show numbers associated with the unique values of categorical features.

Pie charts show numbers associated with the unique values of categorical features where these values are exhaustive, exclusive, and relatively few.

Line charts allow us to visualize numeric data where the x axis consists of numerica data on an ordinal or ratio scale.

Use Cases¶

  • Show trends where x axis is time or other sequential data, for example monthly revenue over a fiscal year, daily average temperature, a patient’s blood pressure across visits, website traffic per week, or population by decade.

  • Compare trends, for example sales of three product lines side by side, unemployment rates in several countries, control vs. treatment groups in a trial, or actual vs. forecast budget.

  • Plot classical mathematical functions, e.g. linear functions like y=mx+by = mx + by=mx+b, for example the parabola y=x2y = x^2y=x2, the sine wave y=sin⁡xy = \sin xy=sinx, exponential decay y=e−kty = e^{-kt}y=e−kt, the logistic curve, or the hyperbola y=1/xy = 1/xy=1/x.

  • Show process types, for example isothermal and adiabatic compression on a ppp–VVV diagram, the heating curve of water through its phase changes, a capacitor charging and discharging, or a stress–strain curve for a material under load.

A simple example¶

So far, we have looked at plots that involve categorical data. Let’s look at a simple example.

Below, we visualize a small data set showing sales number over a series of years.

import pandas as pd
import numpy as np
import matplotlib.pyplot as plt
import seaborn as sns
data = {
    'year': [2021, 2022, 2023, 2024, 2025, 2026],
    'sales': [100, 120, 170, 160, 210, 240]
}
df1 = pd.DataFrame(data)
df1
Loading...

To create a line graph in Pandas, you can just call .plot() by itself. Line graphs are the default plot type.

In the example below, we set xxx to Year and yyy to Sales.

df1.plot(x='year', y='sales')
plt.show()

Of course, we can also call the .line() method explicitly.

df1.plot.line(x='year', y='sales')
plt.show()

Or we can set the kind argument to line

df1.plot(x='year', y='sales', kind='line')
plt.show()

Another simple example¶

In this example, we demonstrate how to plot more than one line in the same figure.

We create data showing number of units sold per month for two products, AAA and BBB.

data = {
    'Month': ['Jan', 'Feb', 'Mar', 'Apr', 'May'],
    'Product_A': [15, 20, 35, 30, 45],
    'Product_B': [25, 18, 22, 40, 48]
}
df2 = pd.DataFrame(data)

df2.plot.line(x='Month', y=['Product_A', 'Product_B'], title="Business is Booming")
plt.show()
Note

It makes sense to show multiple lines in the same figure if their associated features have the same domain.

In the example both lines represent prices of products.

We can show the two lines on separate axes with the subplots argument set to True.

df2.plot.line(x='Month', y=['Product_A', 'Product_B'], subplots=True)
plt.show()

Using Pandas’ indexes¶

As we saw earlier, Pandas defaults to showing the index of a data frame on the x axis if x is left unspecified.

Here we set the index to Month, since the values are uniqure over the observations.

Then, since the remaining non-index features are related, we don’t need to specify those, either. Pandas assumes you want to show them all.

df3 = df2.set_index('Month')
df3.plot()
plt.show()

Here we change the style of plot to show points as well as lines.

df3.Product_A.plot.line(style = '-o')
plt.show()

We can set the attributes of multiple lines by passing lists to the arguments.

df3.plot.line(style=['o-', 's--'], color=['blue', 'green'])
plt.show()

Note that these data can be visualized with a bar chart.

However, they are better visualized with a line graph to show the trend of the data over the numeric sequence.

The bar chart is useful here is you want to emphasize differences between AAA and BBB per month.

df3.plot.bar()
plt.show()
Note

Line graphs and bar charts differ on how they represent domains on the x and y axis.

In contrast to a line graph, in a bar chart:

  • The years on the x axis are treated as categories.

  • The y axis is not clipped but begins with 0. As a rule, bar charts must have a zero baseline.

A better example¶

Let’s look at the mpg dataset provided by Seaborn.

Let’s use these data to see how cars in different coutries have changed over the years

mpg = sns.load_dataset('mpg')

To compare measurement features over year and origin, lets create a wide table with hierarchical columns.

mpg_measures = ['horsepower','mpg','acceleration','weight']
mpg_wide = mpg.pivot_table(index='model_year', columns='origin', values=mpg_measures, aggfunc='mean')
mpg_wide
Loading...

Note the structure of this table.

The series from the index will define the x-axis and the series associated with the columns will define separate y-axis values.

The result will be three plots for eacg aggregated feature.

Comparisons¶

Putting them side-by-side, we can see a couple of things.

First, as mpg went up during the 1970s, horsepower went down.

Second, the United States has favored horsepower over mpg in comparison to Europe and Japan.

fig, ax = plt.subplots(4,1, figsize=(6,12), sharex=True)
for i, col in enumerate(mpg_measures):
    legend = True if i == 0 else False
    mpg_wide[col].plot(ax=ax[i], title=col.title(), legend=legend)
plt.show()

A more complex example¶

Let’s look an example the contains multiple numeric features that can be plotted against time.

John Arbuthnot’s (1710) data set describes male and female births for London from 1629–1710.

These time series data were used to carry out the first known significance test.

During every one of the 81 years, there were more male christenings (i.e. births) than female christenings.

As Arbuthnot asked, is this difference due to chance or did it mean the birth ratio was actually not 1:11:11:1.

data_url = "https://vincentarelbundock.github.io/Rdatasets/csv/HistData/Arbuthnot.csv"
dfx = pd.read_csv(data_url)
dfx = dfx.set_index('Year')
dfx = dfx.drop("rownames", axis=1)
dfx.head()
Loading...

Here are what the column names stand for:

  • Year: The year, ranging from 1629 to 1710.

  • Males: Number of male christenings (births).

  • Females: Number of female christenings (births).

  • Plague: Number of deaths from the Plague.

  • Mortality: Total deaths (all causes combined) for that calendar year.

  • Ratio: Ration of Males to Females.

  • Total: The total number of births scaled in thousands (000s).

Let’s look at the Total number of births during this period.

dfx.plot(y='Total', style='.-', legend=False, title="Total Births per Year")
plt.show()

We can see a big trough between around 1640 and 1665.

Let’s look at all the features together.

To this, we use the subplots argument.

dfx.plot(subplots=True, figsize=(7.5,15))
plt.show()

Showing two y-axis scales on the same axes¶

We two related features come from two domains, it becomes a problem when you try to show them on the same axes.

Matplotlib provides a function to solve this problem -- ax.twinx().

This function take an axes object returned by a Pandas plot an creates a new axes object that will be overlaid on the first, while using the right spine for the new domain.

ax = dfx.Total.plot(style='.-')
ax2 = ax.twinx()
dfx.Plague.plot(ax=ax2, color='orange', style='-')
plt.show()

Plotting mathematical functions¶

Line charts are also useful for plotting classicial mathematical functions, where yyy is a function of xxx, i.e. y=f(x)y = f(x)y=f(x).

df = pd.DataFrame()
df['x'] = np.arange(0, 5 * np.pi, 0.1)
df['sin_x'] = np.sin(df.x)
df.plot(x='x', y='sin_x')
plt.grid(True)
plt.show()
df['cos_x'] = np.cos(df.x)

Plotting processes¶

Line graphs are good at showing processes.

Kinds of process:

  • linear

  • cyclical (e.g. seasonal)

  • exponential

  • volatile

  • multi-Variable (comparative)
