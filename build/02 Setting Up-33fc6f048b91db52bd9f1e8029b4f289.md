## Setting up your environment

### 1 Create a GitHub repo for this class.

Create a private repo on GitHub. Use the template or fork repo for this class.

That repo will contain instructions for creating an environment.

Make the repo private.

Share the repo with the instructor and the greater.

### 2 Create clone of the repo on Afton.

Every student will set up an account on Afton and or their local desktop or some other cloud environment.

Clone the repo into a directory. The directory should be a main directory for everything to do with your class. A good idea is to name that directory ds2023. Going forward. It will be assumed that you have named your directory this way.

Once you have cloned the directory, create a virtual environment for python. This is the python version and set of libraries you will be expected to use in this class.

Follow the instructions for setting up this environment using the requirements.txt file available in the repo.

### 3 How to submit assignments.

All assignments will be submitted as single page Jupiter notebooks within the repo.

The process will be that you create a notebook to complete an assignment. And then you share the URL of that repo and the assignment on canvas. Canvas will provide a text box where you can cut and paste the URL.

There will be a template provided for all assignments.
