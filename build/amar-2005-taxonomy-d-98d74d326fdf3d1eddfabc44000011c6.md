# Analytic Task Taxonomy

A vocabulary of ten low-level (primitive) analysis tasks that largely capture people’s activities
while employing information visualization tools for understanding data.

From Amar, Eagan & Stasko (2005) "Low-Level Components of Analytic Activity in Information Visualization," _IEEE InfoVis_ 2005.

```{note}

The vocabulary from the original have been adapted to the conventions of data science.

Specifically, *data cases* becomes *observations* and *attributes* becomes *variables*.

```

| #   | Task                          | Description                                                                                                                                | Pro Forma Abstract                                                                          | Examples                                                                                                                                                                                                                         |
| --- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 1   | **Retrieve Value**            | Given a set of specific observations, find the values of variables for those observations.                                                 | What are the values of variables {X, Y, Z, ...} for observations {A, B, C, ...}?            | What is the mileage per gallon of the Audi TT? How long is the movie *Gone with the Wind*?                                                                                                                                       |
| 2   | **Filter**                    | Given some concrete conditions on variable values, find observations satisfying those conditions.                                          | Which observations satisfy conditions {A, B, C, ...}?                                       | What Kellogg's cereals have high fiber? What comedies have won awards? Which funds underperformed the SP-500?                                                                                                                    |
| 3   | **Compute Derived Value**     | Given a set of observations, compute an aggregate or other numeric representation of those observations.                                   | What is the value of aggregation function F over a given set S of observations?             | What is the average calorie content of Post cereals? What is the gross income of all stores combined? How many manufacturers of cars are there?                                                                                  |
| 4   | **Find Extremum**             | Find observations possessing an extreme value of a variable over its range within the data set.                                            | What are the top/bottom N observations with respect to variable A?                          | What is the car with the highest MPG? What director/film has won the most awards? What Robin Williams film has the most recent release date?                                                                                     |
| 5   | **Sort**                      | Given a set of observations, rank them according to some ordinal metric.                                                                   | What is the sorted order of a set S of observations according to their value of variable A? | Order the cars by weight. Rank the cereals by calories.                                                                                                                                                                          |
| 6   | **Determine Range**           | Given a set of observations and a variable of interest, find the span of values within the set.                                            | What is the range of values of variable A in a set S of observations?                       | What is the range of film lengths? What is the range of car horsepowers? What actresses are in the data set?                                                                                                                     |
| 7   | **Characterize Distribution** | Given a set of observations and a quantitative variable of interest, characterize the distribution of that variable's values over the set. | What is the distribution of values of variable A in a set S of observations?                | What is the distribution of carbohydrates in cereals? What is the age distribution of shoppers?                                                                                                                                  |
| 8   | **Find Anomalies**            | Identify any anomalies within a given set of observations with respect to a given relationship or expectation, e.g. statistical outliers.  | Which observations in a set S have unexpected/exceptional values?                           | Are there exceptions to the relationship between horsepower and acceleration? Are there any outliers in protein?                                                                                                                 |
| 9   | **Cluster**                   | Given a set of observations, find clusters of similar variable values.                                                                     | Which observations in a set S are similar in value for variables {X, Y, Z, ...}?            | Are there groups of cereals with similar fat/calories/sugar? Is there a cluster of typical film lengths?                                                                                                                         |
| 10  | **Correlate**                 | Given a set of observations and two variables, determine useful relationships between the values of those variables.                       | What is the correlation between variables X and Y over a given set S of observations?       | Is there a correlation between carbohydrates and fat? Is there a correlation between country of origin and MPG? Do different genders have a preferred payment method? Is there a trend of increasing film length over the years? |
