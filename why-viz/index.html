Table vs Chart Recall

DS 2023 | Communicating with Data

Vision Trumps All¶

“Vision trumps all other senses. We learn and remember best through pictures, not through written or spoken words.”

— John Medina, Brain Rules

Exercise Overview¶

We will test this idea by comparing:

  • Memory for a data table

  • Memory for a chart

Speaker Notes:

  • Give students 30 seconds to study the table.

  • Then hide the slide.

  • After ~1 minute, ask recall questions:

    • Which country had the largest GDP?

    • Which two countries had nearly equal GDPs?

    • Roughly how many millions of people live in Japan?

# import plotly.express as px
import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns
sns.set_theme(style='darkgrid')

df = pd.DataFrame(
    dict(
        Country = ["USA","China","Japan","Germany","India","Brazil"],
        Population = [331,1441,126,83,1380,213],
        GDP = [23.0,17.7,4.9,4.2,3.1,1.6]
    )
).set_index('Country')

ax = df.plot.scatter(x='Population', y='GDP', figsize=(10,10))
for idx, row in df.iterrows():
    y_pad = 0 if idx != 'Germany' else -.1
    ax.text(row['Population']+20, row['GDP']+y_pad, idx)
sns.despine()
plt.show()
