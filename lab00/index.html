Lab 0: Setting Up Your Coding Environment

DS 2023 | Communicating with Data | Fall 2026

Instructions¶

In this Lab, you will set up your coding environment so that you can do all the work required in this class. These instructions provide a high-level description of what you need to do; for each task, there are help docs that you can branch out to if you are unsure of what to do.

Tip

You are encouraged to collaborate with your colleagues to get these things done.

Requirements¶

For your files:

It is essential for this class and all other data science courses that you have a place to put your code and a way to share it with others.

  1. A private GitHub repository for your coursework. In general, when you submit homework, you will submit a URL to a notebook in your repo. To use GitHub, you will need to install a couple of other things, such as Git and SSH.

  2. A local directory (aka folder) on your computer’s file system in which you will clone this repo using Git, and where you will conduct all the work for this class.

For your code:

Here is a list of all the software requirements for this class. This is often called your “stack.”

  1. A working installation of Python, a popular programming language for data science. We will be using version 3.12, which is not the latest one. You will define this in your environment (see next item).

  2. A dedicated Python environment for this class with the right versions of Python and required modules. We recommend using conda for this, a command line tool that comes with Miniconda (see below).

  3. A collection of Python libraries that you will use throughout the course, including Pandas, NumPy, Matplotlib, Seaborn, SciPy, and Plotly. Other libraries will be specified as needed.

  4. VS Code or Jupyter Lab, two programming editors. If you use VS Code, you will need to install the extensions for Python and Jupyter.

  5. Jupyter notebooks will be the primary file format for this course. Although not a separate piece of software per se, it is worth highlighting this since these notebooks, which end in .ipynb are not standard Python files, which end in .py.

Note

Although this seems like a lot of stuff, each task just requires following the steps, i.e. there’s no problem solving -- just patience and attention to detail! If you are uncomfortable with the command line, then this will help you become acquainted with it. Also: you will use each of these things throughout your career as a student of data science at UVA.

Install Git¶

Next, you need to make sure you have Git installed on your computer. Git allows you to move files to and from GitHub.

If you don’t have Git installed on your computer, or you are not sure if you do, follow these steps.

For MacOS

  1. Open your Mac’s Terminal app.

  2. Type this exact command and press Enter:

git --version

  1. A popup will instantly appear on your screen asking if you want to install the Command Line Developer Tools.

  2. Click Install, agree to the terms, and let it run.

Once the progress bar finishes in a couple of minutes, Git will be fully installed and ready to use.

For Windows

  1. Go to the URL below and find the link to the standalone installer.

  2. Download and install it.

https://git-scm.com/install/windows

The installer adds a custom terminal called “Git Bash” to your computer. You can use that or the standard Windows Command Prompt. Both will work perfectly.

One of the final setup screens will ask about a credential helper. It defaults to the Git Credential Manager -- you need this, so leave it selected.

Set Up Authentication¶

Note

If you already had git installed and are using SSH or some other means of authenticatin to GitHub, you may skip this step.

Once you have installed Git, you must run these two commands in their terminal to introduce yourselves to Git:

git config --global user.name "Your Name"
git config --global user.email "your_email@example.com"
Caution

Use the exact email address you used to create your GitHub account.

Next, we turn on the password manager so you only have to login once.

For MacOS:

git config --global credential.helper osxkeychain

For Windows:

git config --global credential.helper manager

Great! Now you can use Git and GitHub together!

Create a Local Directory¶

Your next task is to clone the repo you created above so that you have a local version of it. You will do all of your work in this local repo and the push your changes to GitHub so that they are available on the Web.

Before you can do that, though, you need to create a good place to put the repo on your computer. It is strongly advised that you create a directory inside of your documents direcory (“Documents” on both Windows and Mac).

On Windows, this directory is here:

C:\Users\[Username]\Documents

On a Mac, it’s here:

/Users/[Username]/Documents

Of course, you need to replace [Username] with the user name you use to log onto your computer.

Now, under the Documents directory, you may want to create a directory called Courses where you can park all of your data science courses. In any case, create a new directory somewhere under Documents called DS2023. In this directory you will put any files that are important for this class. You will also clone your course repo here.

Clone the Course Repo¶

To clone the repo, follow these steps:

  1. Navigate to the cousre repo ds2023 on GitHub in your browser.

  2. Click the green “<> Code” button.

  3. Make sure the HTTPS tab is selected (it is selected by default).

  4. Click the Copy icon next to the URL. The URL is now in your computer’s clipboard.

  5. Next, open a terminal window and get to the ds2023 directory you created under the Documents directory. From within that directory, enter the command git clone and after that enter a space and then paste the URL from the clipboard. The command should look like this:

git clone https://github.com/<your_github_username>/ds2023

  1. A browser window or small dialog box will open saying “Sign in with your browser”.

  2. Click that button.

  3. A GitHub page will load asking to “Authorize GitCredentialManager”.

  4. Click the green Authorize button and type the GitHub password if prompted.

  5. The browser will say “Authentication Successful!” and can be closed.

From this point forward you can edit files, use git add, git commit, and git push without ever being asked for a password. 😀

Step 6: Test That It Works!¶

To ensure everything is working correctly, students can make a small change and push it back up to GitHub. Run these four commands in sequence:

1. Change directory into the cloned project¶

cd repo-name

2. Stage all modifications¶

git add .

3. Save the changes locally with a descriptive note¶

git commit -m “Testing our new HTTPS connection”

4. Upload the code to GitHub¶

git push

Success check: If the code uploads immediately to GitHub without prompting for a username or password, the Git Credential Manager is officially configured! If anyone runs into a roadblock, let me know:

  • What Operating System generated the error?

  • Did the issue happen during the terminal command step or inside the web browser popup?

Create a Python environment¶

A Python environment is a separate installation of Python on your system that will contain a custom version of Python and collection of libraries. Environments allow you to make sure you have the right versions of libraries and that they don’t conflict with each other.

Tip

In this course, we will be using specific versions of libraries, like Pandas, because they have features that previous versions do not.

You can create Python environments in many ways. A simple and effective way is to use conda, which was installed when you installed Miniconda. Once you have installed conda, run the following command from a terminal window.

Note

If you are on Windows, do this from the Anaconda Prompt icon that was installed when you installed Miniconda.

conda create -n ds2023 -c conda-forge python=3.12 \
  "ipykernel>=7.3" \
  "ipython>=9.15" \
  "ipywidgets>=8.1" \
  "jupyterlab>=4.6" \
  "matplotlib>=3.11" \
  "nbconvert>=7.17" \
  "numpy>=2.5" \
  "pandas>=3.0" \
  "scikit-learn>=1.9" \
  "scipy>=1.18" \
  "seaborn>=0.13" \
  "statsmodels>=0.14" -y

This creates a new environment called ds2023 with the Python version and libraries you need for this course.

Now, to use the environment, you will run this command to activate the environment:

conda activate ds2023

Once the environment is activated, you will be able to access all the code that was installed in it, including jupyterlab.

You will also be able to select this environment to run your notebooks in VS Code.
